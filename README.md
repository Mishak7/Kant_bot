# UniHelper (Kant Bot) 🤖
![](https://static.tildacdn.com/tild6266-3465-4562-b136-346362396536/_8_2024-02_1.jpg)
**UniHelper** - Telegram-бот для иностранных студентов Балтийского федерального университета имени Иммануила Канта (БФУ).

### 🧠 ИИ-тренажер на базе GigaChat и SaluteSpeech 
- 📚 Уровни от A-1 до C-2
- ⭐ Очки за выполненные задания 
- 🎯 Задания на грамматику, письмо, аудирование и говорение 
- 🤖 Умная проверка заданий 
- 💡 Помощь с трудными заданиями 
- 🏆 Доска лидеров 

+ 🏫 Справочная информация по БФУ

+ 🗺 Сервис "Куда сходить?" с умными рекомендациями на основе GigaChat 

### 🚀 Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: pip install -r requirements.txt 
3. Установить ffmpeg и ffprobe:
4. + Windows: скачать с официального сайта 
   + Linux: `sudo apt install ffmpeg`
   + macOS: `brew install ffmpeg` 
5. Создать .env файл с токенами:
```
TELEGRAM_TOKEN="your_telegram_token"
GIGA_CREDENTIALS="your_gigachat_token"
SALUTE_CREDENTIALS="your_salute_token"
FFMPEG_PATH=path_to_FFMPEG
FFPROBE_PATH=path_to_FFPROBE
```
6. **При первом запуске**: БД будет создана и заполнена с нуля - занимает несколько минут, тратит много токенов! Если Вы хотите использовать текущую версию BFU.db без создания БД (чтобы не тратить токены), то свяжитесь с автором - я вышлю последнюю редакцию файла BFU.db

7. Запуск через **main.py**

### 🗂 Структура проекта

- `main.py` - точка входа, создание файла БД
- `config/` 
  - `settings.py` - загрузка переменных окружения
  - `logger.py` 
- `handlers/` - обработчики команд и сообщений
  - `main_handlers/` - главное меню, **словарь** с языками и промпт для проверки username
  - `level_selection_handlers` - основные хэндлеры для тренажера (подбор и вывод заданий, вариантов ответов, проверка, подсказки, выбор уровня, переход между уровням)
  - `language_check_handlers/` - вспомогательные хэндлеры для тренажера
  - `university_handlers/` - информация о БФУ
  - `places_to_visit_handlers/` - рекомендации мест c ИИ
  - `critical_info_handlers/` - важная информация
  - `dormitory_handlers/` - информация про общежития
  - `hospital_handlers/` - информация про медицину 
  - `feedback_handlers/` - хэндлер для отправки фидбэка, найденных ошибок 
  - `location_handlers/` - корпуса
  - `sber_handlers/` - полезные ресурсы от СБЕРа
- `services/` - сервисы
  - `neural_network_communication/` 
  - `database/` - работа с базой данных
    - `database_prompts/` - промпты для БД
    - `database_fill.py` - список заданий, отсюда идет загрузка в BFU.db
    - `database_functions.py` - функции для работы с БД (загрузка заданий, регистрация пользователя, подготовка заданий, запись прогресса)
    - `speech_utils.py` - генерация/транскрибация аудио
  - `grammar/` 
  - `listening/` 
  - `speaking/` 
- `utility_files/`

`BFU.db` - БД с заданиями. Если Вы поменяли что-то в заданиях, то БД будет пересоздаваться с нуля заново (долго и много токенов), поэтому советую улучшить функцию `add_tasks()` или не пересоздавать БД, чтобы не тратить много токенов.

`places.db` - БД с местами для посещения
